GitOps Platform
ArgoCD · Declarative Infrastructure

A fully declarative Kubernetes platform managed entirely through Git. Every resource — namespaces, deployments, ConfigMaps, RBAC, ingress rules — lives in a GitHub repository. ArgoCD continuously reconciles the cluster against this single source of truth with automatic drift detection and self-healing.

Architecture Highlights
  • App of Apps pattern organises platform components hierarchically
  • Auto-sync with self-heal prevents manual drift from accumulating
  • Webhook-triggered sync for sub-30-second deployment latency
  • Git history provides full audit trail and one-command rollback
  • Multi-environment targeting via Kustomize overlays

Metrics API
Real-time Cluster Telemetry Endpoint

A lightweight REST API that exposes real-time cluster health metrics — CPU usage, memory utilisation, running pod count, disk pressure, and uptime — in a clean JSON format. Powers the live dashboard on this portfolio site and enables external monitoring integrations.

Architecture Highlights
  • FastAPI / Python backend running as a Kubernetes deployment
  • Queries Prometheus federation endpoint for real-time TSDB data
  • Exposed via Traefik ingress at platform.bvrinfra.in/api/metrics
  • CORS-enabled for cross-origin access from portfolio frontend
  • Rate limiting and read-only RBAC for public safety

Kubernetes Homelab
Proxmox · K3s · Production Patterns

A 3-node Kubernetes cluster running on Proxmox VMs that mirrors enterprise production patterns. The cluster runs a dedicated control-plane node, a workload node for applications, and a separate observability node — isolating monitoring resource consumption from application workloads.

Architecture Highlights
  • 3 VMs on Proxmox: master (control plane), worker1 (apps), worker2 (obs)
  • MetalLB provides bare-metal load balancer IP allocation
  • Cloudflare Tunnel for zero-trust external access — no open ports
  • Node taints and tolerations separate observability from app workloads
  • Persistent volumes backed by local-path provisioner with encryption

Observability Stack
Prometheus · Grafana · Loki · Promtail

A complete metrics, logs, and alerting stack providing full visibility into platform health. Prometheus collects time-series metrics from every cluster component. Loki aggregates structured logs from all pods. Grafana unifies both data sources into correlated dashboards for rapid root-cause analysis.

Architecture Highlights
  • Prometheus scrapes 15+ targets with automatic service discovery
  • Promtail DaemonSet ships logs from all nodes to Loki
  • Pre-built dashboards: cluster overview, node metrics, app health
  • AlertManager routes P1 alerts to email with 5-minute SLA
  • 30-day retention with automated cleanup CronJobs
