Component Breakdown

Stack Components

☸️
K3s Kubernetes
Container Orchestration

Lightweight, production-ready Kubernetes distribution from Rancher. Runs on Proxmox VMs with a single control-plane node (k8s-master) and two worker nodes (k8s-worker1 for workloads, k8s-worker2 as the observability node). K3s bundles containerd, Flannel CNI, and etcd — eliminating heavy dependencies while maintaining full K8s API compatibility.

Control Plane etcd Flannel CNI containerd 3-node cluster
🦉
Traefik Ingress
Ingress Controller + Reverse Proxy

Cloud-native edge router serving as the Kubernetes ingress controller. Paired with MetalLB for bare-metal load balancing, Traefik handles TLS termination, routing rules, and automatic service discovery via Kubernetes IngressRoute CRDs. Exposes all subdomains under bvrinfra.in through Cloudflare Tunnel for secure remote access without open firewall ports.

IngressRoute CRDs TLS Termination MetalLB Cloudflare Tunnel
🐙
ArgoCD
Continuous Delivery — GitOps Engine

Declarative GitOps tool that continuously reconciles the Kubernetes cluster state with manifests stored in GitHub. Any git push triggers ArgoCD's sync loop: it diffs the desired state in Git against the live cluster, applies only the delta, and self-heals drift automatically. All platform resources — namespaces, deployments, ConfigMaps, secrets — are version-controlled and auditable.

App of Apps pattern Auto-sync Self-heal GitHub integration Drift detection
🔥
Prometheus
Metrics Collection & Storage

Time-series metrics engine deployed on k8s-worker2 (the dedicated observability node). Scrapes metrics from all Kubernetes nodes, pods, and services via service discovery and kube-state-metrics. AlertManager processes alert rules and routes notifications. Retention is configured for 30 days with automated cleanup jobs preventing unbounded disk growth.

Node Exporter kube-state-metrics AlertManager 30d retention
📊
Grafana
Observability Visualisation

Unified dashboarding layer pulling from both Prometheus (metrics) and Loki (logs). Pre-provisioned dashboards for Kubernetes cluster overview, node resource usage, pod lifecycle, and application performance. Accessible externally at grafana.bvrinfra.in with role-based access control. Alerting configured for resource threshold breaches and pod crash loops.

Prometheus datasource Loki datasource RBAC Pre-built dashboards Alert rules
📋
Loki + Promtail
Log Aggregation Pipeline

Grafana Loki provides horizontally scalable, multi-tenant log aggregation without full-text indexing — storing only labels and compressed log chunks for cost efficiency. Promtail is the agent deployed as a DaemonSet on every node, tailing container logs and pushing them to Loki with Kubernetes metadata labels (namespace, pod, container) for powerful log correlation with traces.

DaemonSet agent Label-based index Grafana integration LogQL queries
🔄
GitOps Workflow
Deployment Pipeline

All infrastructure changes flow through Git. The workflow: developer commits YAML manifests → GitHub webhook notifies ArgoCD → ArgoCD syncs to cluster → health checks verify rollout → Prometheus/Grafana validate metrics post-deploy. Rollback is a single git revert commit. No manual kubectl applies in production — every change is auditable and reversible.

GitHub source of truth Declarative config Git revert rollback Audit trail
🔐
Backup Strategy
Disaster Recovery & Data Protection

Four-layer backup approach: (1) K3s State DB — etcd snapshots preserving cluster state; (2) Manifests Backup — all K8s resource definitions; (3) Infra Git Backup — configuration history; (4) Encrypted Off-Cluster — AES-encrypted backups to external storage. Automated retention policies and cleanup jobs run on schedule via CronJobs.

etcd snapshots AES encryption Off-cluster storage CronJob automation Retention policies

ArgoCD Sync Trigger

Kubernetes liveness/readiness probes confirm workload health. AlertManager fires if thresholds breach.
